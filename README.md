# 问道 · 斗法（联机版）

《问道·斗法》的最新联机版本：保留完整的卡牌、精魄、反制、眩晕、增益与单机 AI 规则，并增加房间号 1v1。

**线上地址**：<https://wendao-doufa.onrender.com>  
**GitHub**：<https://github.com/apollyonGIT/projXian>

> 对局数据优先走 WebRTC 点对点直连；直连失败才回退 Render 中继。若长期只能走中继，美国 SF 节点到国内实测 RTT 约 600–900ms，建议另建 Singapore 服务。

## 开始游戏

### 公网联机

1. 双方打开线上地址。
2. 一人点「联机论剑」→「创建房间」。
3. 复制邀请链接或 5 位房间号给好友。
4. 好友打开链接/输入房间号加入。
5. 房主点「开始对战」。

房主操控左侧 **云归**，加入者操控右侧 **朱衣客**。
房主浏览器负责战斗模拟，对局期间必须保持游戏标签在前台。

### 本机运行

```bash
npm install
npm start
# http://localhost:3000
```

## 操作

| 输入 | 招式 |
| --- | --- |
| `W A S D` | 移动（移动中回灵 20/秒）；同时按住相反方向时，**后按下的方向优先** |
| 鼠标左键 | 挥剑，**不消耗灵力**，近战伤害 10；对手进入近战范围时自动索敌；命中回 60 灵力 |
| 鼠标右键 | 御灵飞射（**按住可连发**），消耗 10 灵力，伤害 5；命中回 25 灵力 |
| 右键·反制 | 对方近战刀光出现期间按右键：不发射灵子，改为**反制**，把对方扔出去并眩晕 2 秒；**反制后 0.5 秒内无法御灵**（6 秒冷却，左侧面板显示） |
| 空格 | 贴地闪避，单次使用，2 秒冷却；冲刺距离翻倍、期间无敌 |
| `1` – `5` | 施放手牌中对应位置的卡牌（等价于拖拽出牌） |
| 拖拽卡牌 | 把卡牌拖到场中施放；巨剑术/缩地按落点生效，玄武锤释放即可眩晕对手；**在卡牌区松开则放回手牌** |
| `Esc` | 打开设置（联机对局中不打开设置） |

> 联机对局中，顶部中间的「离开」按钮退出房间；战斗设置使用房主当前保存的值。客机手牌与卡牌拖拽同样可用。

## 当前规则要点

- **灵力 100**：站定每秒回 40、移动每秒回 20；出招后的 0.5 秒内停止回灵。灵力达到 100 时自动转化为 1 精魄，余下灵力保留（例如 90 + 60 → 50 灵力 + 1 精魄）。
- **御灵不要求灵力充足**：每次发射灵子消耗 10 灵力，但灵力为 0 时也能发射；不足 10 点时扣到 0，最少为 0。
- **精魄即“费”**：每 6 秒自动 +1（上限 10），灵力满 100 也会自动 +1。
- **卡组 22 张 / 手牌 5 张**：巨剑术 3 费、轻身术 1 费、桃 3 费、金手指 0 费、打坐 0 费、缩地 1 费、嗜血奇术 2 费、玄武锤 2 费、顺手牵羊 1 费。**每局开始时双方牌库都会重新洗牌**；每个槽位会预抽一张牌，普通牌打出后由该槽位的预抽牌顶上；**金手指**会把整个手牌与预抽牌一起洗回牌库再重摸。
- **敌方 AI 也会出牌**：对手同样有手牌、牌库与精魄，会按局势使用巨剑术、轻身术、桃、缩地、嗜血、玄武锤、顺手牵羊、金手指与打坐；**AI 出牌手速上限为 1.5 秒一张**；非卡牌行为沿用旧版节奏（前 2 发免灵、连射 4 发后转近战清连击），反制会在玩家刀光出现时立即尝试；**AI 每秒最多挥一剑**（近战冷却仍是 0.38 秒，但 1 秒内只会出一次剑；决定出剑而间隔未到时原地等待，等待期间不发射灵子）；低血/低灵力时只会在被贴近时拉开距离，不会在远处来回踱步。
- **眩晕只封印行动，不封印卡牌**：被眩晕时仍然可以打出手牌。
- **闪避单次**：没有蓄能层数，用完后 2 秒冷却；冲刺距离是原先的两倍。
- **近战出手间隔 0.38 秒**（只是动作间隔，没有额外冷却）；拼刀成功会立即刷新双方近战出手与闪避冷却。
- **近战与灵子不能同时使用**：挥剑刀光存在期间无法发射灵子。
- **拖牌撤回**：左键按住卡牌拖动后，**在卡牌区（手牌区）松开左键**即视为没有打出，卡牌留在原槽位。
- **每局随机牌序**：开局时玩家与 AI 的牌库都会重新洗牌，起手 5 张与后续抽牌顺序每局不同。
- **顺手牵羊是一次性技能**：不会出现在 BUFF/DEBUFF 栏；固定偷取对手**最新获得**的一个增益，该增益会从对手身上消失，并在自己身上以完整持续时间重新生效（已有同名增益则重置时间）；对手没有可偷增益时无事发生，不消耗精魄。
- **顺手牵羊+**：顺手牵羊发动后，**同一手牌位置**会出现临时牌「顺手牵羊+」（**2 费**）；**5 秒后自动销毁**，并从牌库随机刷新一张牌补到该位置；它也可以主动打出。**不会以任何方式进入牌库**（打出、销毁、金手指洗牌都会排除它），卡面右上角显示剩余秒数。
- **轻身术可解晕**：释放轻身术时会**解除自身一次眩晕**，并正常获得移速加成。
- **眩晕会打断打坐**：打坐期间被眩晕命中会立即中断读条，这一次打坐**不会获得 2 费**。
- **眩晕期间仍可出牌**：眩晕只封锁移动、近战、灵子、闪避、反制；手牌照常可用，敌我规则一致。
- **打坐读条**：打坐时人物头顶会显示一条进度条，方便判断何时入定完成。
- **上方 BUFF 栏**：双方头顶面板会显示增益/减益图标与倒计时秒数——增益（轻身术、桃、嗜血）统一**绿色**，减益（眩晕）统一**红色**。
- **增益视觉表现**：桃生效时人物身上会持续冒出**绿色小加号**；嗜血生效时周身环绕**暗红血气与血环**；轻身术生效且移动时，身后会拖出**青色风痕**。
- **桃一局最多 3 次**：卡面会显示「已用 x/3」；用尽后桃会**从本局手牌与卡组中移除**，下一局初始化时重新加回；AI 同样受限。
- **AI 不再空挥**：剑必须落在真实命中距离内才会挥出，且不会为了刷新连击而故意空挥。
- **拼刀**：双方剑光同时（都还未命中）触发，双方**本次都不受近战伤害**，闪避冷却清零并各回 **75 灵力**；拼刀回灵**不叠加**近战命中的 60 点（同时发生按拼刀判定）。
- **反制**：对方近战刀光期间按右键，不会发射灵子，而是打断对方挥剑、把他朝反方向扔出去并**眩晕 2 秒**（受首次攻击伤害即解除）；**6 秒冷却**，左侧「反制」面板显示剩余时间；**AI 也会反制**；**反制成功后 0.5 秒内无法御灵**，防止连点灵子误伤眩晕目标，同一次按住也不会在锁定结束后自动续射。
- **AI 近战不再频繁绕圈**：贴身时多数时间正面压迫，只偶尔侧步找角度。
- **近战不再销毁灵子**：弹反机制已移除，只能用闪避或走位躲灵子。
- **对波**：相向的灵子会轻微互相吸附，对波成功后**后发射者固定获得 60 灵力**。
- 近战攻击时，若对手已在可命中的近战范围内，剑锋会**自动索敌**，不再要求鼠标精确对准，也不再要求先有掩体视线；起手后的 75ms 前摇内剑锋会继续跟踪目标，对手小幅后撤/横移也能命中（约 18×scale 的补正）。
