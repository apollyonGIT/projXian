# 问道 · 斗法

一款可直接在浏览器中运行的单页修仙即时斗法游戏，支持单人挑战 AI，也支持房间号 1v1 公网联机。

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/apollyonGIT/projXian)

一键部署：<https://render.com/deploy?repo=https://github.com/apollyonGIT/projXian>

## 运行

### 单机版

无需安装依赖、无需构建：双击 `index.html`，或用任意静态服务器打开即可。

### 联机版（公网 1v1）

联机需要 Node.js 静态服务 + WebSocket 房间中继：

```bash
npm install
npm start
# 打开 http://localhost:3000
```

也可以使用 `pnpm install` / `pnpm start`。页面右上角选择「联机论剑」：房主创建房间并复制邀请链接，好友打开链接或输入 5 位房间号加入，房主点击「开始对战」。

联机采用**房主权威同步**：房主浏览器运行战斗模拟，客机发送操作并接收快照。房主保持页面开启，对战期间双方都能实时操作。房间号仅用于好友约战，不设密码，请勿公开传播。

## 部署到公网

### Render（推荐）

1. 把除 `node_modules`、`release` 外的文件提交到 GitHub 仓库。
2. Render 新建 Web Service，连接仓库。
3. Build Command 填 `npm install`，Start Command 填 `npm start`，Health Check Path 填 `/healthz`。
4. 部署完成后打开 Render 给出的 `https://...onrender.com` 地址；把网址和房间号发给朋友即可。

也可以直接使用仓库内的 `render.yaml` 创建 Blueprint。Render 免费实例空闲后会休眠，首次唤醒可能需要等待几十秒。

### Railway / 其他 Node 平台

项目带有 `Procfile`，平台识别 Node 后运行 `npm start` 即可。需要支持 WebSocket Upgrade 和 HTTPS/WSS。

> 联机不能只把单文件 HTML 放到静态网页空间：必须部署 `server.js` 提供的 WebSocket 服务。

## 联机限制

- 房主电脑负责战斗模拟，因此房主几乎没有延迟，客机延迟取决于网络。
- 房主关闭页面或离开房间会结束对局；当前版本不支持断线重连。
- 联机使用房主保存的近战范围、灵子初速与移动速度设置；客机不可修改。
- 联机对局不会写入单人 AI 的出招记忆。
- 建议双方使用桌面版 Chrome / Edge 与键鼠；窄屏页面可以显示，但移动仍需要键盘。
- 房间码为 5 位、无密码，适合熟人约战；请勿公开房间链接。

## 操作

| 输入 | 招式 |
| --- | --- |
| `W A S D` | 移动（每秒消耗 3 点灵力） |
| 鼠标左键 | 朝鼠标方向挥剑，近战伤害 20 |
| 鼠标右键 | 朝鼠标方向发射灵子，基础伤害 10 |
| 空格 | 贴地闪避，2 秒冷却；冲刺期间无敌，下一击强化 |
| `F` | 开始打坐，每秒回复 20 灵力，5 秒冷却；已在打坐时再按无效 |
| `Esc` | 在战斗中打开设置（设置面板会暂停模拟） |

页面底部的技能按钮同样可点击，并显示按键、当前状态与冷却时间。

## 核心规则

- 双方均为 200 气血、100 灵力，使用同一套规则。
- 近战首次耗灵 5 点，之后连续近战逐次翻倍。
- 灵子前 2 发完全免灵；从第 3 发起消耗 5 点，然后按 5、10、20、40……逐次翻倍。切换攻击方式会重置另一套连击。
- 近战连击与灵子连击分别显示在顶部，且分别增加 / 重置。伤害不随距离衰减。
- 当下一记近战与下一记灵子都无力支付时，进入灵力枯竭：每秒损失 5 点气血，直到灵力恢复到足以出招。
- 打坐可持续回灵，移动、出招、闪避、受击都会打断；`F` 只负责入定，不会主动结束打坐。
- 闪避后的下一击伤害翻倍且免灵力，角色周身出现金色灵光。
- 成功闪避近战或灵子后，自身的近战连击与灵子连击都会重置。成功闪避近战还会朝远离攻击者的方向弹射一段距离。
- 双方剑光同时存在时触发拼刀：迸发火花、打出金属声并刷新双方闪避冷却。
- 双方灵子对撞会同时湮灭；后发射的一方返还该发灵子的全部耗灵，并额外获得 10 点灵力。
- 石块与树木会阻挡移动、飞射物和穿过掩体的近战挥砍；对手会规划绕行路径。

## 敌方修士

朱衣客会频繁御使灵子压迫对手，并根据气血、灵力、距离、掩体与威胁选择逼近、换招、闪避、弹反、绕行和打坐。它的灵子连击达到 4 后，会优先用可命中的近战清势；若近战够不到但灵子压制收益很高，它会以一剑清势后立即发射灵子；若没有明显收益，则暂不刷新，继续观势寻找机会。它也会利用闪避强化反击；当你近身压制且它气血充足时，它会优先游斗而不是过早消耗打坐冷却。

最近 5 场斗法的玩家近战 / 灵子使用倾向会保存在浏览器本地。累计足够对局后，朱衣客会适度模仿你的出手节奏，同时仍根据当前局势判断。

## 设置与存档

- 「近战范围」与「灵子初速」由双方共享。近战实际判定与剑光半径使用同一参数。
- 「移动速度」以当前基础移速为 100%，可调至 300%，敌我双方共享；该设置不改变闪避冲刺距离。
- 设置保存于浏览器 `localStorage`，下次打开游戏自动沿用。
- 对局记忆同样保存在本地，只保留最近 5 场。

## 文件

- `index.html` — 页面结构、HUD、开始 / 设置 / 联机大厅 / 结算界面
- `styles.css` — 东方修仙视觉、响应式布局、界面动效
- `game.js` — 固定步长战斗循环、Canvas 渲染、碰撞、路径搜索、AI 与联机客户端
- `server.js` — Node 静态托管、WebSocket 房间中继与心跳
- `package.json` — Node 运行依赖与启动命令
- `render.yaml` / `Procfile` — 云平台部署配置
- `release/` — 可发送给朋友的打包文件（单机单文件版与联机部署包）
